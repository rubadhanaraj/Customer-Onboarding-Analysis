# Customer-Onboarding-Analysis
Customer onboarding process improvement using Tableau

## Project Overview
This project analyzes a simulated customer onboarding process to identify inefficiencies and improve implementation outcomes. The goal is to understand how different factors impact onboarding duration and customer success.

---

## Live Dashboard
View the interactive Tableau dashboard here:  
(https://public.tableau.com/app/profile/ruba8664/viz/CustomerOnboardingDashboard/CustomerOnboardingProcessImprovementDashboard)


---

## Dataset Description
The dataset includes simulated onboarding data with the following fields:
- Customer ID
- Signup Date
- Onboarding Start and End Dates
- Support Tickets (number of issues raised)
- Training Completion (Yes/No)
- Status (Completed, In Progress, Delayed)

---

## Key Insights
- Customers with higher support tickets experience longer onboarding durations  
- Training completion is associated with faster onboarding  
- Delayed customers show significantly longer onboarding timelines
